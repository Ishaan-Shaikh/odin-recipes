# Odin Recipes

## Project Overview
A foundational HTML project building a simple recipe website. The site features a main index page with links to multiple recipe pages, each containing ingredients, steps, and images of the finished dishes.

## Skills Demonstrated
By completing this project, I have demonstrated:
- **HTML5** document structure with proper boilerplate
- **Semantic headings** (h1, h2, etc.) for content hierarchy
- **Links** - absolute and relative paths, navigation between pages
- **Lists** - unordered (ingredients) and ordered (steps)
- **Images** - embedding and basic attributes
- **Directory organization** - logical file structure
- **Git fundamentals** - staging, committing with meaningful messages
- **GitHub** - repository creation and README documentation
